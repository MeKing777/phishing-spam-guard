Local browser protection

Set up Alerter

Alerter automatically checks website addresses and page links, warns about risky destinations, and can block common ad and tracker requests. It scans visible Gmail inbox previews as you scroll and open messages in Gmail or Outlook. You can also ask it to read and check text in the currently visible tab. Its Python checker and optional screen OCR run on this computer.

1. Start the local checker

  1. Run the checkerDouble-click start_alerter_checker.bat in the project folder. Keep its window open while browsing. Screen scanning also needs Tesseract OCR installed; Alerter looks in the standard Windows installation folder.
  2. Open your browser's extension pageChrome: chrome://extensions · Edge: edge://extensions · Brave: brave://extensions · Firefox: about:debugging#/runtime/this-firefox
  3. Load AlerterFor Chrome, Edge, Brave, or Opera, enable Developer mode and choose Load unpacked. For Firefox, choose Load Temporary Add-on and select the Firefox folder's manifest.json.
  4. Use it while browsingVisit a website or open Gmail or Outlook. Click Alerter to scan page links, visible Gmail previews, or the open message. Choose Scan visible screen to capture the current tab once and read its visible text locally.

Permission note: Background link and email checks require permission to read pages you visit, including visible webmail content. A screen image is captured only after you click its scan button; the image is read by local OCR, used for the check, and discarded. Alerter does not upload scan content to a cloud service or delete email.

The extension package targets desktop Chrome, Edge, Brave, Opera, and Firefox. Browser extensions are not supported in the same way on every mobile browser; Safari requires a separate signed package. Link and email checks are indicators, not a guarantee that a low-risk result is safe.
